# PRD 2단계: 인식된 식재료로 레시피 추천

## 1. 목표
1단계에서 확정한 식재료 목록과 사용자가 고른 조건으로 AI 텍스트 모델이 한국어 레시피를 추천한다.

## 2. 기술 결정
| 항목 | 결정 |
|---|---|
| 텍스트 모델 | `nvidia/nemotron-3-super-120b-a12b:free` (수업 지정 모델) |
| 예비 모델 | 텍스트 무료 모델 중 다른 것으로 자동 전환(1단계와 같은 재시도·예비 모델 규칙) |
| 화면 | 1단계와 같은 Streamlit 앱의 다음 단계 |

## 3. 사용 흐름
1. 1단계에서 "레시피 추천받기"를 누르면 2단계로 넘어가고, 레시피 생성이 **자동으로 시작**된다.
2. 제목 바로 아래에 사용할 식재료가 회색 타원 칩으로 한 줄에 보인다.
3. 조건 드롭다운 4개를 바꾸고 "다시 추천받기"를 누르면 새로 생성한다.
4. 같은 화면에서 식재료 칩과 레시피 카드를 함께 보며 서로 맞는지 확인한다.
5. "← 이전"으로 1단계 목록 편집에 돌아가거나, "처음부터"로 사진 올리기부터 다시 시작한다.

## 4. 기능 요구
### 4.1 레시피 조건
| 조건 | 선택지 |
|---|---|
| 종류 | 한식, 양식, 중식, 일식 |
| 난이도 | 초급, 중급, 고급 |
| 조리 시간 | 15분 이내, 30분 이내, 30분 이상 |
| 인원 | 1인분, 2인분, 3인분, 4인분 |

3단계에서 로그인한 사용자는 프로필에 저장한 값이 기본값이 된다.

### 4.2 AI 생성
- 레시피 3개를 만든다. 프롬프트에 **모든 내용을 한국어로만 작성**하라고 분명히 적는다.
- 응답 형식:
  ```json
  {"recipes": [{
    "title": "김치볶음밥", "summary": "한 줄 소개", "cuisine": "한식",
    "difficulty": "초급", "time_minutes": 20, "servings": 2,
    "used_ingredients": [{"name": "김치", "amount": "1컵"}],
    "missing_ingredients": [{"name": "참기름", "amount": "1큰술"}],
    "steps": ["1단계 설명", "2단계 설명"],
    "tips": "선택 사항"
  }]}
  ```
- 냉장고에 있는 재료를 최대한 쓰게 하고, 부족한 재료는 `missing_ingredients`에 따로 적게 한다.
- 영어로 답하거나 JSON이 깨지면 실패로 보고 재시도 규칙을 적용한다.

### 4.3 결과 표시
- 레시피마다 카드에 제목, 소개, 시간, 난이도, 인원, 사용할 재료, **부족한 재료(강조 표시)**를 보여 준다.
- "자세히 보기"를 펼치면 조리 순서와 팁을 보여 준다. 카드마다 이 버튼의 높이를 맞춘다.
- 실제로 응답한 모델 이름과 몇 차 시도에 성공했는지 표시한다.

### 4.4 실패 보고
- 생성에 실패하면 "레시피 생성 실패"와 원인을 화면에 남긴다. 이전 결과를 이번 결과처럼 보여 주지 않는다.

## 5. 완료 기준
- 1단계 목록으로 한국어 레시피 3개가 자동으로 생성된다.
- 조건을 바꾸면 그 조건이 반영된 레시피가 나온다.
- 부족한 재료가 구분되어 보인다.
- 응답 파싱과 프롬프트 생성에 대한 자동 시험이 통과한다.
