# PRD 1단계: 냉장고 사진에서 식재료 인식

## 1. 목표
사용자가 냉장고 사진을 올리면 AI 이미지 모델이 사진 속 식재료를 찾아 목록으로 보여 주고, 사용자가 그 목록을 직접 고칠 수 있게 한다. 이 목록은 2단계(레시피 추천)의 입력이 된다.

## 2. 기술 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 화면 | Streamlit | 파이썬만으로 화면을 만들고, 결과를 가장 빨리 확인할 수 있음 |
| 배포 | Streamlit Community Cloud | 무료이고 설정이 가장 적음(깃허브 저장소에서 바로 배포) |
| AI 호출 | OpenRouter Chat Completions API | 무료 모델을 키 하나로 사용 |
| 이미지 모델 | `google/gemma-4-26b-a4b-it:free` | 수업 지정 모델 |

## 3. 사용 흐름
1. 사용자가 사진을 고르거나 끌어 놓는다(jpg, jpeg, png, webp).
2. 사진 미리보기가 보인다.
3. "식재료 인식하기"를 누르면 진행 상태(축소 → n차 시도 → 예비 모델 전환 → 완료)가 보인다.
4. 같은 화면에서 사진 옆(좁은 화면에서는 아래)에 인식된 식재료 목록이 보인다.
5. 사용자가 목록을 고친 뒤 "레시피 추천받기"로 2단계에 넘어간다.

## 4. 기능 요구
### 4.1 사진 처리
- 긴 변이 1024px를 넘으면 비율을 유지한 채 줄이고, JPEG(품질 85)로 다시 압축한 뒤 보낸다.
- 휴대폰 사진의 회전 정보(EXIF)를 반영해 바로 세운다.
- 원본 크기와 보낸 크기를 화면에 표시한다.

### 4.2 AI 인식
- 프롬프트는 다음을 지시한다.
  - 먹을 수 있는 식재료만 고르고, 용기·비식품은 제외한다.
  - 낱개로 셀 수 있는 것은 실제 개수를 센다.
  - 이름은 한국어로 쓴다.
  - 결과는 JSON 하나로만 답한다.
- 응답 형식:
  ```json
  {"ingredients": [{"name": "달걀", "quantity": 6, "unit": "개", "category": "유제품/달걀"}]}
  ```
- 분류는 채소, 과일, 육류, 해산물, 유제품/달걀, 양념/소스, 음료, 가공식품, 기타 가운데 하나로 한다.
- 응답이 코드 블록에 싸여 있거나 앞뒤에 설명이 붙어 있어도 JSON 부분만 뽑아 읽는다.

### 4.3 재시도와 예비 모델
- 1순위 모델로 최대 3차 시도까지 한다. 대상은 429와 5xx 오류, 그리고 빈 응답이나 JSON이 아닌 응답이다. 시도 사이에는 2초, 4초를 기다린다.
- 그래도 실패하면 이미지 입력을 지원하는 다른 제공자의 무료 예비 모델로 넘어간다.
- 화면에는 지금 몇 차 시도인지, 어느 모델로 넘어갔는지 표시하고, 결과에는 실제로 응답한 모델 이름을 표시한다.
- 무료 등급의 하루 한도(429, 하루 50회)에 걸린 것인지, 모델이 잠시 혼잡한 것인지 구분해서 안내한다. 하루 한도는 한국 시각 오전 9시에 초기화된다.

### 4.4 목록 편집
- 한 줄에 이름, 수량(+/- 버튼이 있는 숫자 입력), 단위 드롭다운, 삭제 버튼을 놓는다. 단위는 개, 병, 봉지, 팩, 단, 통, g, kg, ml, L, 기타 가운데 고른다.
- 식재료를 직접 추가할 수 있다.
- 이름이 같은 재료는 하나로 합치고 수량을 더한다.
- 각 행은 고유 id로 구분해서, 중간 행을 지워도 다른 행이 지워지지 않게 한다.
- 목록 위에 "AI 인식 결과는 틀릴 수 있으니 확인해 주세요"라고 안내한다.

### 4.5 실패 보고
- 인식에 실패하면 "식재료 인식 실패"와 그 원인을 화면에 분명히 보여 준다. 이전 사진의 결과를 남겨 두어 이번 결과처럼 보이게 하지 않는다.

## 5. 비기능 요구
- API 키는 로컬에서는 `.env`의 `OPENROUTER_API_KEY`, 배포 환경에서는 Streamlit Secrets에서 읽는다. 키를 화면이나 로그에 출력하지 않는다.
- 요청 제한 시간은 60초로 한다.
- AI 호출 로직은 화면 코드와 분리된 모듈에 두어, 화면 없이도 시험할 수 있게 한다.

## 6. 완료 기준
- 실제 냉장고 사진으로 인식 결과 목록이 나온다.
- 1순위 모델이 실패해도 예비 모델로 결과가 나오거나, 실패가 화면에 정직하게 표시된다.
- 목록의 수정, 삭제, 추가가 동작한다.
- 응답 파싱, 중복 병합, 이미지 축소에 대한 자동 시험이 통과한다.
